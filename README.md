# CODE FATALITY

Story-driven coding arena — learn HTML, CSS, and more by writing real code in a Mortal Kombat–inspired fight UI.

Working brand name (easy to swap in `apps/web/src/config/brand.ts`).

## Run locally

```bash
cd apps/web
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Phase 1 (current)

- Arena landing + world map
- **HTML Village** quests + boss
- **CSS Forest** starter quests (unlock after HTML boss)
- Monaco editor, live preview, client-side validation
- Progress saved in `localStorage`
