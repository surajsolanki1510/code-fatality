# Code Fatality assets

Drop your files here (same names). Placeholders work until then.

| File | Purpose |
|------|---------|
| `hero.png` | Your fighter (transparent PNG best) |
| `enemy.png` | Bug / boss fighter |
| `arena.mp4` | Looping arena background video |
| `arena.webm` | Optional WebM fallback |

SVG placeholders (`hero.svg`, `enemy.svg`) show until PNGs load.
Poster fallback for missing video: `/art/world-html.jpg`
